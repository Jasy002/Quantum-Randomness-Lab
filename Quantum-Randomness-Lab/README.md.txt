# Quantum Randomness Laboratory


## Mini Project 1

This mini project demonstrates a Quantum Random Number Generator (QRNG) using Qiskit in Google Colab.

## Objective

To generate quantum random numbers using quantum superposition and compare them with classical random numbers.

## Tools Used

- Python
- Google Colab
- Qiskit
- NumPy
- Matplotlib

## Features

- Quantum Random Number Generator
- Histogram Visualization
- Statistical Analysis
- Classical vs Quantum Randomness

## Output

The project generates random quantum bits, displays their distribution using a histogram, performs statistical analysis, and compares the results with classical random number generation.
